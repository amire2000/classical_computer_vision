# Classical Computer Vision Course

A C++20, OpenCV-based practical course in classical computer vision: image
foundations, geometry, motion and tracking, navigation, time-to-contact, and
systems integration for a final UAV-vision capstone.

Start with [Module 0: Setup Your Environment](docs/modules/00_setup_environment/index.md),
then follow the full [course roadmap](classical_computer_vision_course_roadmap.md).

## Quick start

```bash
cmake --preset debug
cmake --build --preset debug
./build/debug/modules/00_setup_environment/hello_opencv
```

Read [Module 0](docs/modules/00_setup_environment/index.md) for Ubuntu
dependencies, VS Code tasks, and the local MkDocs Material site.
