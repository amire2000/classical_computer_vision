# Classical Computer Vision Course

A practical C++20 and OpenCV course covering image foundations, geometry,
motion, tracking, navigation, time-to-contact, and systems integration for a
UAV-vision capstone.

## Start here

1. Complete [Module 0: Setup Your Environment](modules/00_setup_environment/index.md).
2. Follow [Module 1: Images, Memory, and the Vision Pipeline](modules/01_image_foundations/index.md).

## Local documentation site

```bash
uv venv
uv pip install -r requirements-docs.txt
.venv/bin/mkdocs serve
```

Open the address printed by MkDocs to browse the course locally.
